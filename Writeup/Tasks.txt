Part 1: Getting Started with ROS

Project objective

I plan to establish a working ROS development environment and bring up a TurtleBot3 or TurtleBot4 in the simulated maze. This part establishes the simulation environment for later perception and navigation work.

Subtask 1: Setting up ROS

My goals are to:
- Set up a working ROS environment on my system.
- Become familiar with the ROS command-line interface and basic concepts such as nodes and topics.
- Capture screenshots of ROS CLI commands to document the working setup.

Why this matters
A working ROS environment is the foundation for developing and integrating robot software. Understanding nodes and topics helps me inspect how robot programs communicate and diagnose problems in later parts of the project.

Learning outcomes
I should understand the role of ROS, recognize its basic communication concepts, and use its CLI to inspect a running robotics system.

Subtask 2: Bringing up the TurtleBot in the maze

My goals are to:
- Use the upstream turtlebot-maze repository to bring up a TurtleBot3 or TurtleBot4 in the maze world.
- Display the robot and maze in Gazebo and RViz2.
- Capture screenshots of both applications showing the robot in the maze.

Why this matters
Simulation allows me to inspect robot behavior and sensor data before working with physical hardware. Gazebo represents the simulated physical environment, while RViz2 visualizes the information available to ROS.

Learning outcomes
I should understand the difference between simulation and ROS visualization, recognize the robot and its sensor data in the simulated environment, and demonstrate a functioning robotics application.

Relevant constraints and concepts

I plan to use Docker-based development with the upstream repository. ROS distributions must match their supported Ubuntu versions when installed natively; my available Ubuntu 24.04 EC2 instance is suitable for a Jazzy-based setup. Remote graphical access is a practical requirement of my EC2 environment so I can view the required applications.

I will document the working environment with ROS CLI screenshots and Gazebo/RViz2 screenshots showing the TurtleBot in the maze. This part focuses on environment setup and simulation. A navigation demonstration provides additional verification before later perception and exploration work.
