Assignment 1: Getting Started with ROS
Assignment source: https://aegean.ai/aiml-common/assignments/main/robotics-spring-2026/assignment-1

Assignment objective

I need to establish a working ROS development environment and bring up a TurtleBot3 or TurtleBot4 in the required simulated maze. The assignment has two graded tasks, each worth 50 points.

Task 1: Setting up ROS — 50 points

I need to:
- Set up a working ROS environment on my system.
- Become familiar with the ROS command-line interface and basic concepts such as nodes and topics.
- Capture screenshots of ROS CLI commands as evidence of the setup.

Why this matters
A working ROS environment is the foundation for developing and integrating robot software. Understanding nodes and topics helps me inspect how robot programs communicate and diagnose problems in later assignments.

Learning outcomes
I should understand the role of ROS, recognize its basic communication concepts, and use its CLI to inspect a running robotics system.

Task 2: Bringing up the TurtleBot in the maze — 50 points

I need to:
- Use the course turtlebot-maze project to bring up a TurtleBot3 or TurtleBot4 in the required maze world.
- Display the robot and maze in Gazebo and RViz2.
- Capture screenshots of both applications showing the robot in the maze.

Why this matters
Simulation allows me to inspect robot behavior and sensor data before working with physical hardware. Gazebo represents the simulated physical environment, while RViz2 visualizes the information available to ROS.

Learning outcomes
I should understand the difference between simulation and ROS visualization, recognize the robot and its sensor data in the simulated environment, and demonstrate a functioning robotics application.

Relevant constraints and concepts

The assignment recommends Docker-based development and the course repository. ROS distributions must match their supported Ubuntu versions when installed natively; my available Ubuntu 24.04 EC2 instance is suitable for a Jazzy-based setup. Remote graphical access is a practical requirement of my EC2 environment so I can view the required applications.

The required submission consists of ROS CLI screenshots and Gazebo/RViz2 screenshots showing the TurtleBot in the maze. The assignment page does not specify AI model training, an exploration algorithm, or a navigation-performance benchmark. Any additional navigation demonstration is optional verification.
